สร้างไฟล์ Template กรอกข้อมูลเงินเดือน

เลือกบริษัทลูกค้า เปลี่ยนเดือนทุกชีต ใส่รายได้–รายหัก (และชั่วโมง OT ถ้ามี) จากรายงานเงินเดือน empeo แล้วดาวน์โหลดไฟล์ส่งลูกค้าก่อนรอบคำนวณ

งวด —
บริษัทนี้ไม่ใช้ไฟล์ Template ส่งไฟล์จาก empeo ให้ลูกค้าโดยตรง (รายงานเงินเดือน Excel ใส่รหัสผ่าน และ PDF รายงาน OT001) ใช้หน้านี้สำหรับ Payroll Plan และอีเมลถึงลูกค้า
1

บริษัทลูกค้าและไฟล์ต้นแบบ

ใช้ไฟล์ Template ของเดือนก่อน (เช่น Asian Asphalt_Template กรอกข้อมูล 10.2026.xlsx) ทุกชีต สูตร และรูปแบบจะถูกคงไว้ตามเดิม

จำไว้แล้ว

2

งวดเงินเดือน

ตั้งเป็นเดือนปัจจุบันให้อัตโนมัติ เดือนนี้จะไปแทนที่หัวกระดาษของชีต New Employee, Resign, ChangeInfo, PVF และ Income - Deduct

วันจ่ายดึงจากชีต “รอบ” ของไฟล์ต้นแบบ แก้ได้ถ้าเลื่อนวันจ่าย ระบบจะใส่ในคอลัมน์ “วันจ่ายเงิน” เป็น พ.ศ. ตามรูปแบบเดิม

3

รายงานเงินเดือนจาก empeo

ใช้เติมชีต Income - Deduct และ สรุป ชม OT ที่พนักงานขอ

หน้าเว็บนี้เข้า empeo หรือ Partner Portal เองไม่ได้ (ต้องใช้การล็อกอินของคุณ) ให้ export รายงานตามขั้นตอนด้านล่าง แล้ววางไฟล์ในกรอบนี้ หรือให้ Claude ทำผ่าน Chrome ให้

  1. เข้า empeo ของลูกค้าผ่าน Partner Portal → Customer → ⋮ → Remote Support › Payroll แล้วไปที่ เงินเดือน → เลือกงวดของเดือนนี้ แล้วกด คำนวณเงินเดือน
  2. ในหน้างวดเดียวกัน กด ไฟล์เอกสาร → รายงาน → รายงานเงินเดือน → ทั้งหมด
  3. นำไฟล์ที่ได้ (เช่น Payroll_Report_Period_11_02112026.xlsx) มาวางด้านล่าง ระบบจับคู่คอลัมน์และรหัสพนักงานให้เอง
เปิด Partner Portal

หลัง export จาก empeo กด "ดึงรายงานล่าสุดจาก Downloads" ครั้งแรกให้เลือกโฟลเดอร์ Downloads หนึ่งครั้ง

4

Payroll Plan และอีเมลถึงลูกค้า

กำหนดการของรอบนี้คำนวณจากวันจ่ายในขั้นตอนที่ 2 นับเฉพาะวันทำการ ดาวน์โหลดรูปและ Excel แล้วให้ Claude ร่างอีเมลใน Outlook ให้คุณกดส่ง

งานฝั่ง empeoงานฝั่งลูกค้าวันที่เงินเดือนออกเสาร์–อาทิตย์วันหยุด
รายการผู้รับผิดชอบวันทำการก่อนวันจ่าย

0 = วันจ่าย, 1 = วันทำการก่อนหน้า 1 วัน ข้อมูลนี้บันทึกแยกตามบริษัท

อีเมลถึงลูกค้า

ตัวอย่างที่ลูกค้าจะเห็น

ส่งอีเมล: ดาวน์โหลดรูปและ Excel Plan ไว้ใน Downloads แล้วกด และวางในแชท (คำสั่ง: ) Claude จะเปิด Outlook บน Chrome กรอกผู้รับ หัวเรื่อง ข้อความ และแนบไฟล์ให้ แล้วรอคุณตรวจและกด Send เอง
ถ้า Claude ติด limit: กด แตกไฟล์แล้วดับเบิลคลิกไฟล์ .eml จะเปิดเป็นอีเมลร่างใน Outlook (แอปบนเครื่อง) พร้อมผู้รับ หัวเรื่อง ข้อความ และไฟล์แนบ ตรวจแล้วกด Send ได้เลย
ส่งเองผ่าน Outlook Web (ไม่ต้องใช้ Claude):
  1. กด (รูป + Excel Plan ลงโฟลเดอร์ Downloads)
  2. กด เปิดร่างใน Outlook Web จะได้อีเมลใหม่ที่ใส่ผู้รับ CC หัวเรื่อง และข้อความไว้แล้ว
  3. ลากไฟล์ทั้ง 2 จาก Downloads ไปวางในอีเมล ตรวจแล้วกด Send
ถ้าลายเซ็นของ Outlook ใส่ให้อัตโนมัติอยู่แล้ว ลบลายเซ็นในช่องลายเซ็นของหน้านี้ออก จะได้ไม่ซ้ำ
